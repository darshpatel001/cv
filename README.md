# Darsh Patel — Engineering Portfolio

A responsive creative-dark portfolio made with plain HTML, CSS and JavaScript for GitHub Pages.

## Before publishing

Update the placeholders in `index.html`:
- `YOUR_EMAIL@example.com`
- `YOUR-GITHUB-USERNAME`
- `YOUR-LINKEDIN-USERNAME`

Review every project description and status label. They are deliberately described as development, learning, architecture or evaluation work where appropriate. Replace or expand them with verified results, screenshots, repository links and test evidence.

Optional:
- Add your resume as `assets/Darsh-Patel-Resume.pdf` and add a resume link.
- Add project screenshots or hardware photographs.
- Link each project card to its source repository or technical write-up.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
2. Upload the contents of this folder to the repository root. `index.html` must be at the root.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for the Pages deployment. Your site address will be `https://YOUR-GITHUB-USERNAME.github.io/`.

## Local preview

Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes

- No backend, database, package manager or build step is required.
- GitHub Pages is static hosting. A working contact form requires a third-party form service or a separate backend.
- Google Fonts are loaded online; system font fallbacks are provided.
- The ambient canvas animation respects the browser's reduced-motion preference.
